# 🎬 Movie Search App

A simple and user-friendly Movie Search App built using **HTML, CSS, and JavaScript**. It allows users to search for their favorite movies and explore movie details, ratings, and information.

## ✨ Features
- Search movies by name.
- View movie details and ratings.
- Simple and responsive user interface.
- Easy-to-use design.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Movie API

## 🚀 Getting Started
1. Clone this repository.
2. Open the project folder.
3. Run `index.html` in your browser.
